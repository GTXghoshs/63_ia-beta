# Código de Conduta

A participação no 63_ia (beta) deve ser respeitosa, técnica e colaborativa. Não serão tolerados assédio, discriminação, ameaças, exposição de dados pessoais, abuso de credenciais, envio deliberado de código malicioso ou tentativa de ampliar permissões sem revisão.

Discussões devem se concentrar no problema, evidência, reprodução e solução. Relatos de segurança devem seguir `SECURITY.md` e não ser usados para constranger contribuidores ou usuários.

O mantenedor poderá editar, fechar ou remover contribuições que violem este código ou coloquem usuários em risco. A interpretação final cabe ao mantenedor do projeto, com prioridade para segurança, respeito e transparência.
