Limites de segurança

O modo padrão aceita somente comandos simples de leitura. Não há shell, sudo, redirecionamento, pipes ou execução encadeada.

Comandos disponíveispwdls -lahdf -hfree -hnprocuname -allama-server --versionvulkaninfo --summarylspci -k

Não é um sandbox forte. Use uma conta Linux dedicada para tarefas não confiáveis.
